# 青云志 · 宗门纪事

一个修仙宗门经营向文字游戏。你是宗主，不是打手——宗门的方向由你定，宗门里的事由弟子自己发生。

**打开方式**：双击 `index.html`，用浏览器打开即可。无需安装、无需联网。

宗门会**自己运转**。你可以随时暂停、或者挂到 4 倍速去泡杯茶。

---

## 一句话玩法

> 用灵石买物资 → 放进仓库 → 弟子用贡献点自己换 → 弟子变强 → 接更重的活 → 带回更多灵石和物资。

你唯一直接控制的是**灵石怎么花**、**收谁进门**、以及**时间快慢**。其余的，弟子们自己会做。

---

## 时间与倍速

| 操作 | 说明 |
|---|---|
| `❚❚` | 暂停。宗门完全静止，你可以从容地买东西、看弟子 |
| `1×` | 一年约 **20 秒** |
| `2×` | 一年约 **10 秒** |
| `4×` | 一年约 **5 秒** |
| 空格键 | 暂停 / 恢复到上次倍速 |

顶栏下方那条进度条就是**当前这一年的进度**，走满自动进入下一年。

**事件是"播"出来的，不是一次性倒出来的。** 每年结算产生的事件会进入播报队列，在这一年里匀速滚进「宗门动态」，所以看起来是弟子们在各处同时活动，而不是每到年末刷一大屏。

### 离线收益

- 离线效率 **50%**，单次最多补算 **24年**，离开不足 1 分钟不算
- 回来会弹一份「你离开了多久 / 宗门运转了几年 / 期间的要事」
- **暂停状态下离开没有收益**——暂停就是真的停

## 宗门里会发生什么

年报不是日志，是一卷一卷的短篇。每一年开头都有一句定调的话：

> 雾从后山漫上来，一整年都没散。宗门里安静得能听见煮茶的声音。

然后才是这一年具体的事：

> 叶汐把那具兽尸拖回山门时，半边身子都是血。守门的弟子吓了一跳，他却先开口："内丹在口袋里，别弄丢了。"说完才蹲下去，手抖得厉害。
> <sub>— 贡献 +21 · 灵石 +32 · 名望 +1</sub>

叙事正文负责"读起来像故事"，灰色小字负责"信息不丢"。两者分开，互不干扰。

### 什么进年报，什么不进

年报只留"事"：任务成败、历练、冲突、突破、大比、剧情线、江湖往来。

**每年打坐、兑换补药、养伤、建筑空转**这些流水账不进年报——它们记在
弟子详情页的「**近况**」里，想看随时能翻。

一卷年报因此从 22 条压到十八九条（三十多人的宗门），读起来不再像账本。

## 三个互相咬合的系统

### 1. 词条：弟子的底子

入门时随机带 1–3 条，分凡品/珍稀/稀世/天命四档。词条**同时影响成长速度和行为倾向**，基本不可更改。

- **天灵根**（天命）修炼 +60%，突破 +10%
- **懒散**（凡品）修炼 −25%
- **痴情**（珍稀）会偷偷喜欢上一个同门；那个人受伤时，他几年都练不进去功
- **天煞孤星**（稀世）修炼 +70%，但身边同门替他挡灾
- **大器晚成**（珍稀）炼气期很慢，筑基后越来越快
- **丹道天赋**（珍稀）丹道 +35，炼丹产出更好
- **御人之术**（稀世）御人 +30，招贤馆能挖到更好的人
- **手残**（凡品）器道 −26，炼器效率低

词条里还有一套**技艺加成**（丹道 / 器道 / 商道 / 御人），直接决定这名弟子在建筑里能干出什么活。

### 2. 弟子之间的关系

关系是**具体的状态**，不只是好感数字：

```
陌路 → 相识 → 好友 → 知己 → 生死之交
                              ↘ 结义（歃血为盟，最多三次）
       ↘ 不和 → 仇敌 → 死敌
道侣（双向确认，一方动心不算）
```

- **好感增长有边际递减**：越亲近越难再进一步，所以「知己」是有分量的
- **好感越高，翻脸伤得越重**
- **关系越好、一旦破裂越痛**：道侣分手会让双方心情长期低落
- **深仇不会自己消散**，轻度不和会随时间淡去
- 结为道侣后会**双修**（双方修为受益），一方受伤另一方魂不守舍
- 有道侣的人不容易叛逃

关系变化时，年报里会有旁白：

> 陆杳绾与段缈成了知己。有些话，不必对别人说，只说给他们两个听。

### 3. 江湖人物（NPC）

十个有名字、有脾气、有立场的人，分布在六个区域。

**每个人有两套好感**：

- **对宗门**：高了会主动上山送东西、送人、报信；低了会来劫货、堵人
- **对某个弟子**：高了会私下塞好处给那个弟子——宗门未必知道，但东西确实进了库房

他们还有各自的**偏好**：云姑不耐烦胆小的，玄玑子只指点悟性高的，裴擒虎见青云宗的人就来气。

好感会随时间自然回落。想维持交情，就得有人常去看看。

|---|---|---|---|
| 辛老 | 坊市老掌柜 | 落霞谷 | 精明、嘴碎、讲信用 |

## 宗门本身：规模、等级、驻地

这三件事是拆开的，各管各的。

### 规模决定能收多少人

| 规模 | 容量 | 扩建价 |
|---|---|---|
| 茅庐 | 6 | — |
| 小院 | 12 | 2500 |
| 庄院 | 20 | 7000 |
| 山门 | 30 | 18000 |
| 洞天 | 44 | 45000 |
| 福地 | 60 | 100000 |

**跟等级无关**。想多收人，花钱扩地。

### 等级由声望 + 最强实力评定

一个没有强者的宗门，名声再响也只是空架子。所以每升一级，**两个指标都得达标**：

| 等级 | 声望 | 最强弟子战力 |
|---|---|---|
| 2 | 90 | 45 |
| 3 | 240 | 100 |
| 4 | 500 | 180 |
| 5 | 900 | 300 |
| 6 | 1500 | 480 |
| 8 | 3800 | 1150 |

哪一项卡住就升不上去。界面会告诉你还差多少。

### 驻地决定一套得失

搬一次家，换一套规则。**没有纯赚的选址**：

| 驻地 | 利 | 弊 |
|---|---|---|
| 青竹后山 | 安稳、年俸低 | 灵气平平、商路远 |
| 落霞谷口 | 拍卖行有高档货、招徒容易 | 修炼慢、年俸加两成 |
| 黑风岭 | **灵矿产量翻倍**、年俸最便宜 | 妖兽多、拍不到稀罕物 |
| 云梦泽 | **修炼快近三成**、地方大 | 年俸最贵、招不到人 |
| 断魂原 | 任务高一档、声望快三成 | 弟子容易折在这儿 |
| 皇城郊 | 声望快四成半、招徒极容易 | 修炼最慢、年俸最贵 |

搬迁要花灵石，还会**掉一成声望**、伤弟子心情。

### 年俸与灵矿

养人是持续开销：**境界越高、身份越高，每年越贵**。
长老的开销是杂役的四倍多。

灵田和灵矿都出灵石：灵田是零星小钱（挑剩下的灵材拿去卖），灵矿才是大宗。
前期货少，光靠灵田也能活；想扩人就得把灵矿开起来。
驻地选黑风岭时**产量翻倍**，但弟子出门也更容易出事。

发不出年俸，弟子忠诚会掉。**钱不够就先扩灵矿，别急着扩人**。

## 江湖：势力、人物与传承

地图上的关系分两种：

| 类型 | 谁 | 会不会老死 |
|---|---|---|
| **势力** | 落霞坊市、落霞拍卖行、山下县衙、铁剑门、游方说书人 | 不会 |
| **个人** | 云姑、阿蛮、玄玑子、瞎子李、白小楼 | 只有白小楼会（82 岁） |

**好感不再是只涨不跌。** 越高越难涨（接近上限时增幅趋近于零），且长期不来往会回落。势力落得快，隐世之人落得慢——他们本就难得一见。

### 不请自来

归墟、断魂那种地方，弟子一辈子也去不了几回。所以那两位**偶尔会自己摸上山来**。

瞎子李站在山门外，没人看见他怎么上来的：

> 执事要请他进去坐，他摆了摆手："我不进门。"他在门槛外站了很久，侧着耳朵，忽然说："你们这山门底下，埋着东西。"说完转身就走，竹杖点在石阶上，一下一下，慢慢下山去了。

玄玑子会坐在门槛上晒一天太阳，临走丢下一句"三年之内，别往北走"。

这种来访也给好感，也能触发传承——不用等弟子跑到归墟去。

### 支线（剧情线）的收尾奖励

五条剧情线走完最后一幕，当事人会留下一件东西：

| 线 | 奖励 | 类型 |
|---|---|---|
| 旧怨 | **释怀** | 词条（修炼 +10%、忠诚 +6） |
| 古碑 | **古碑拓片** | 认主之物（突破 +10%、修炼 +5%） |
| 铁剑门 | **断剑** | 认主之物（战力 +18%、修炼 +3%） |
| 妖患 | **妖王骨笛** | 认主之物（受伤 −18%、福缘 +15%） |
| 心结 | **解结** | 词条（修炼 +8%、受伤 −10%） |

### 认主之物

**天底下只有一件。**

- 跟着主人走，别人拿不走
- 主人死了（寿元、战死、渡劫）也就没了——不会掉到仓库，也不会传给下一个
- 弟子详情里单独一栏「随身之物」，标注「认主 · 他人不可用」
- 纪事里留下记录，标 `[支线]`

同一件东西不会同时出现在两个人身上。剧情线可以重复触发，但如果那件东西已经有主了，后来的人就拿不到。

### 宗门纪事

年报标签页最下面有一块**宗门纪事**，专记两样东西：

**魔劫四章**——哪一年打的、胜败、对应的词条现在在谁手上

**传承名录**——谁从谁那里得到了什么，标着「在世 / 已故」。人死了，这件事还留在册子上。

这两样都不进年报流水（那里一年一换），是长期档案。

### 魔劫也会给弟子词条

打完主线的那一章，**参战的人里战力最高的那个**会拿到一枚专属词条：

| 章 | 词条 | 效果 |
|---|---|---|
| 魔气南侵 | **御魔** | 战力 +8%，受伤 −12% |
| 魔潮压境 | **铁壁** | 受伤 −28%，忠诚 +5 |
| 魔将现身 | **斩将** | 战力 +16% |
| 魔渊决战 | **镇渊** | 战力 +22%，修炼 +6%，突破 +5% |

文本是这样的：

> 某某从那片焦土里走回来时，整个人都不一样了。多年以后宗门里提起这一战，说的都是他——「斩将」这个名号，是从这儿来的。

同样唯一：人死了，词条就断了，主线不会再重打，所以是真的失传。

---
### 传承的唯一性

**一个传承词条，同时只有一个弟子能持有。**

- 传出去之后，别人再够格也拿不到——得等
- 拿到的人死了（寿元到、战死、渡劫没过去、叛出宗门），词条随之消失，这时才轮到下一位
- 面板上会显示：`已传 · 在某某身上` / `可再传 · 上一位已不在`

一个人可以同时拿多条传承，但同一条不会被两个人拿着。

### 传承

每个势力/人物都挂着一场**传承**。好感够、弟子也够格，才会触发。触发后那名弟子拿到一个**只能从剧情里来的词条**，而且只有一次。

| 谁 | 条件 | 得到 |
|---|---|---|
| 落霞坊市 | 好感 70 + 懂买卖 | **识货**（交易 +20） |
| 落霞拍卖行 | 好感 70 + 天赋 78 | **慧眼**（交易 +18、福缘） |
| 山下县衙 | 好感 65 + 道心 68 | **官面**（声望 +18%） |
| 铁剑门 | 好感 ≥ -10 + **打得过裴擒虎** | **剑意**（战力 +16%） |
| 游方说书人 | 好感 70 + 悟性 72 | **江湖耳**（历练收获 +25%） |
| 云姑 | 好感 52 + 会炼丹 | **药性通神**（丹道 +32） |
| 阿蛮 | 好感 60 + 有福缘 | **妖缘**（福缘 1.7） |
| 玄玑子 | 好感 55 + 悟性 78 | **窥道**（突破 +12%） |
| 瞎子李 | 好感 50 + 道心 72 | **听风**（受伤 −42%） |
| 白小楼 | 好感 50 + 练剑的料 | **快剑**（战力 +20%） |

铁剑门那条比较特别：不用讨好他，**打服他就行**。

120 年正常经营大约能拿到 3~4 个传承。

## 大事件与魔劫

宗门不再只是自己长——每隔一段，有东西来撞它。

### 常规考验（每 15~25 年一次）

兽潮、邻宗比武、旱灾、古墓现世。

事件出现时**游戏会自动暂停**，等你决断。每个事件给你两三个选项：

> 【兽潮】黑风岭的妖兽成群下山，一路啃到山脚下。
> 倾巢而出｜精锐迎击｜闭山不出

判定很简单：**派出去的人，战力加起来够不够**。弹窗会直接告诉你胜算：

> 预计战力 640 / 需 520 · 胜算约 85%

赢了拿声望、灵石、稀有掉落；输了死人、受伤、掉声望。选"闭山不出"能保住人，但名声要坏。

### 魔劫（主线，四章）

第 60 / 115 / 175 / 250 年各来一次。

- 第 60 年：魔气南侵
- 第 115 年：魔潮压境
- 第 175 年：魔将现身
- 第 250 年：魔渊决战

**打不过不会垮。** 只是会留下「**魔劫余烬**」：

| 效果 | |
|---|---|
| 修炼速度 | **−20%** |
| 招徒概率 | **+50%** |

一直持续到下一章开打。绝境出人才——这一代修不成，来的人多的是。

### 奖励：阵法与灵宝

打赢主线能拿到**永久加成**，各占三个格子：

**阵法**：聚灵阵（修炼 +12%）、护山大阵（受伤 −25%）、聚宝阵（矿产 +20%）、镇魂阵（忠诚）、诛邪阵（对魔物 +30%）

**灵宝**：镇宗剑（战力 +10%）、山河印（声望 +25%）、万民伞（招徒 +40%）、传功玉牒（修炼 +10%、突破 +8%）

宗门面板会显示当前有哪些、还差几个位置。

## 宗门组织：身份与建筑

### 身份序列

```
杂役弟子 → 外门弟子 → 内门弟子 → 亲传弟子 → 长老
                                    （宗主是玩家，不在序列里）
```

| 身份 | 修炼 | 贡献 | 怎么来 |
|---|---|---|---|
| 杂役弟子 | ×0.80 | ×0.85 | 入门默认 |
| 外门弟子 | ×1.00 | ×1.00 | 入宗满八年 + 有功劳，自动升 |
| 内门弟子 | ×1.18 | ×1.15 | **只能在宗门大比夺魁** |
| 亲传弟子 | ×1.38 | ×1.32 | 内门身份 + 宗主钦点 |
| 长老 | ×1.55 | ×1.45 | 亲传晋升，宗主任命 |

身份决定了三件事：修炼快慢、贡献倍率、**能不能进某些建筑**。

### 建筑

六处地方，可以入驻弟子。入驻的弟子**不再外出跑任务**，但在里面干活、也修炼（只是慢一半）。

| 建筑 | 产出 | 需要 | 最低身份 |
|---|---|---|---|
| 灵田 | **灵石** + 灵材 | 不需要技艺 | 杂役 |
| 丹房 | 丹药（消耗灵材） | 丹道 | 外门 |
| 器阁 | 器物（消耗玄铁） | 器道 | 外门 |
| 账房 | 灵石（自动买卖） | 商道 | 内门 |
| 藏经阁 | 全宗门修炼加成 | 不需要 | 内门 |
| 招贤馆 | **自动招徒**（有空位直接入门） | 御人 | **长老** |

- 建筑 1~4 级，升级加名额、提效率
- **招贤馆由长老坐镇**：眼光好，招来的人资质更高；宗门有空位就当场入门，不用你一个个点
- **一键派遣**：把空闲弟子按技艺自动分派到各处。
  丹道最高的进丹房、器道最高的进器阁，杂役先去灵田。
  只动"完全空闲"的人——正在做任务、养伤、已在别处干活的一概不碰
- **自动补位开关**：开了之后，每年结算时自动重复上面这件事，不用再手动点
- **入驻弹窗会列出这处已经有哪些人**，空的位子也会画出来
- 一个弟子同一时间只能待在一处。弹窗底部会列出「在其他建筑」的人，
  点「调入」先变成「确认调入」，**再点一次才真调过去**——避免手滑把人从别处拽走
- **没料的时候炉子会空转**——记得给丹房留灵材，给器阁留玄铁
- 账房会卖掉仓库里积压超过 3 件的东西，也会趁行情低自动囤货
- 藏经阁的人数越多，每人分到的越薄（它加成的是「不在建筑里的人」）

### 宗门大比

每 **10年**一次。杂役、外门、内门参加，亲传和长老不参赛（他们是裁判）。

- 单败淘汰，最多 16 人（人多时按战力取前 16）
- 胜负 = 战力 × 临场发挥。差距太大翻不了盘，差距不大就可能爆冷
- **关系会影响出手**：遇上仇敌往死里打，遇上道侣会留手
- 擂台有风险，输的人有几率挂彩
- 夺魁者**直接晋入内门**——这是外门弟子唯一的上行通道
- 即便没夺魁，杂役能连赢两场也会被破格提拔为外门

大比是全游戏叙事密度最高的部分：

> 【决赛】两人打得难分难解，裁判数到十，宋峥没能起来。
>
> 【夺魁】柳萤拿下了这一届大比。执事把名册递到宗主案前，上面新添了一行字——柳萤，内门。

## 境界、天劫与寿元

**炼气期**是打基础。三五年升一重，熬到炼气九层已经很不容易。

**炼气九层往上，每一关都要渡劫。**

能不能过，看的是天赋：资质、悟性、道心都算进去，词条也能加成
（**雷霆之体** +15%，**天劫加身** −15%）。境界越高，劫越重。

没过的话两种情况：

- 多半是**重伤**——修为倒退大半，躺好几年，再想冲一次得从头攒
- 有一定概率**直接身死**。劫云散了，原地只剩一枚烧变形的腰牌

**寿元**：每个境界都带来额外寿数。

| 境界 | 大概能活 |
|---|---|
| 凡人 | 90 岁 |
| 炼气九层 | 280 岁 |
| 筑基后期 | 470 岁 |
| 金丹后期 | 900 岁 |
| 元婴后期 | 1730 岁 |

寿元到了就走了，不管修为多高。弟子卡片上写的是「**年龄 / 寿元**」。

所以宗门不是只进不出——一百多年下来，会有一批人自然老去，也会有人死在雷劫里。

## 剧情线：让年报变成连载

单发事件读多了会腻——今天打架，明天和好，后天又打架，彼此没有关系。

所以加了一套**剧情线（Saga）**：一条线跨越数年，分三幕，每年只推进一幕。玩家会在年报里连着看到：

> 【旧怨 · 一】一桩小事闹到了执事那里。许渊尘说连棠先动的手，连棠说许渊尘嘴太脏。执事听完，把两个人都赶了回去。事情没解决，只是被按下了。
> <sub>— 第 1/3 幕</sub>

> 【旧怨 · 二】许渊尘这几年格外用功，天不亮就上后山。有人问他为什么，他只说"不想输给人"。他说的那个人，不必问也知道是谁。
> <sub>— 第 2/3 幕</sub>

> 【旧怨 · 三】许渊尘和连棠隔着三步远站定。演武台下站满了人，谁也没说话。执事本来要拦，被长老按住了手——"让他们打。打完了，这道坎就过去了；打不完，留着也是祸。"
> <sub>— 第 3/3 幕</sub>

第三幕的结局是**真的随机的**，会写进关系里：

> 两人打了半个时辰，最后同时停了手。连棠先开的口："算了。"许渊尘愣了半天，点了点头。这件事之后，两人再没红过脸。

或者：

> 苏岚赢了，但赢得很不体面。连霄川被扶下去的时候，回头看了他一眼。那一眼，在场的人都记住了。

### 目前五条线

| 线 | 触发 | 三幕 |
|---|---|---|
| **旧怨** | 两名弟子交恶到一定程度 | 结怨 → 暗中较劲 → 演武台摊牌 |
| **古碑** | 第 18 年后，弟子在古战场撞见异象 | 异象 → 探查 → 开启秘境 |
| **铁剑门** | 裴擒虎对宗门好感跌破 -12 | 截货 → 登门 → 三局两胜 |
| **妖患** | 第 30 年后，山下村子出事 | 求救 → 追查 → 井底恶斗 |
| **心结** | 第 24 年后，某个弟子心情长期低落 | 消沉 → 长谈 → 后山练剑 |

规则：
- 同时最多两条线在跑，每年最多推进一幕——不会一年涌出七八段剧情
- 每条线跑完后有 40~60年冷却，同类故事不会连着来
- 当事的弟子如果中途叛逃或被逐，故事会中断（有一句交代）
- 山门页顶部有「**正在上演**」区块，能看到哪些事还没完、进行到第几幕

## 弟子交互事件

20 种成对事件，按双方状态与关系筛选：

**正面**：切磋、论道、扶持、喝酒、结伴下山、赠礼、夜谈
**负面**：争执、动手、约战、偷窃、嫉妒、背后议论、误会
**道侣专属**：双修、拌嘴

事件会受词条影响——好斗的更容易约战，狡诈的会偷东西，孤僻的不爱凑热闹。

## 想自己加内容？

- **加词条**：`js/data/terms.js`，`effects` 支持
  `growthMul / powerMul / contributionMul / lootMul / injureMul / breakthroughAdd /
  loyaltyDrift / conflict / fortune / skim / pillDiscount / growthByTier`
- **加物资**：`js/data/items.js`，`effect` 支持
  `exp / tianfu / wuxing / daoxin / heal / guard / breakBonus / purify / power`
- **加区域**：`js/data/regions.js`，`loot` 产出权重，`flavor` 区域专属小事件
- **加任务**：`js/data/missions.js`，按 `tier` 分档
- **加 NPC**：`js/data/npcs.js`，需要 `region / role / desc / likes(d) / meet[] / mood{...}`
- **加弟子事件**：`js/systems/events.js` 的 `PAIR_EVENTS`，写 `cond(a,b,st)` 和 `run(a,b,st)`，
  用 `bond(a,b,delta,out,week)` 改好感（会自动处理阶段跃迁）
- **加建筑**：`js/data/buildings.js`，需要 `cost / upgrades / slots / keySkill / minRank / flavor / output`，
  并在 `js/data/ranks.js` 的 `canEnter` 里给对应身份开权限
- **加身份**：`js/data/ranks.js`，改 `growth / contrib / canEnter` 即可
- **调大比**：`js/systems/tournament.js` 顶部的 `INTERVAL`（每几年一次）和 `MAX_PLAYERS`
- **加剧情线**：`js/data/sagas.js`，写 `canStart(st, week)` 返回演员，再加 `stages` 三幕
  （每幕有 `title / wait / text(ctx) / effect(ctx)`，effect 返回额外的叙事句数组）
- **加叙事**：`js/data/stories.js`，每类写 2–3 个变体，返回 `{text, meta}`
- **调节奏**：`js/core/time.js` 的 `WEEK_MS` / `OFFLINE_EFF` / `OFFLINE_CAP`；
  关系平衡在 `js/systems/relations.js` 的 `change()` 里（边际递减曲线）

改完刷新页面即可生效。旧存档会由 `state.js` 的 `migrate()` 自动升级
（纯数字好感会被转成关系结构体）。
